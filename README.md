# Fashion Portfolio Website

A modern and responsive **fashion portfolio website** built with **React, Vite, and TailwindCSS**.  
This project showcases fashion collections, design work, and personal style in an elegant, fast, and mobile-friendly way.

---

## 🚀 Features

- 🎨 **Responsive Design** – Optimized for desktop, tablet, and mobile.  
- ⚡ **Vite + React** – Super fast development and production builds.  
- 🎭 **TailwindCSS** – Utility-first styling for clean and flexible design.  
- 🖼️ **Portfolio Showcase** – Sections for displaying fashion projects and work.  
- 🔗 **React Router** – Smooth client-side navigation between pages.  
- 🌐 **Netlify Deployment** – Easily deployed with CI/CD support.

## 🛠️ Installation & Setup
clone the repo:
```
git clone https://github.com/kumarvishal01971/Fashion_Portfolio.git
cd Fashion_Portfolio
```
Install dependencies:
```
npm install
```
Run development server
```
npm run dev
```
Build for production
```
npm run build
```
Preview production build locally:
```
npm run preview
```
